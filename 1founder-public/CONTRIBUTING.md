# Contributing

This repository contains the public-facing documentation and open-source components for [1Founder](https://1founder.ai).

## What's here

- `/docs` — Architecture and product documentation
- `/examples` — Sample outputs and data structures
- `/packages/payment-gateway` — Open-source multi-gateway payment abstraction

## Contributing to `@1founder/payment-gateway`

Pull requests welcome for:
- Additional gateway support (PhonePe, PayU, CCAvenue)
- Better TypeScript types
- Test coverage
- Documentation improvements

Bug reports and feature requests via GitHub Issues.

## The core platform

The 1Founder AI boardroom (agents, orchestration, synthesis) is proprietary and not open source. If you're building something similar and want to discuss architecture, reach out via [1founder.ai](https://1founder.ai).
